# Frontend (Next.js Chat Interface)

This directory is designated for the Next.js frontend application in upcoming phases.

## Planned Scope
- Next.js (App Router, React 19 / TypeScript).
- Modern chat UI for real-time conversational streaming with enterprise AI agents.
- Server-Sent Events (SSE) / WebSocket streaming.
- Markdown rendering, tool execution inspection, and latency metrics.
- Authentication state management and session handling.
